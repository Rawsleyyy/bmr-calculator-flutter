# BMR Calculator App 🧮

Aplikasi Kalkulator **Basal Metabolic Rate (BMR)** berbasis mobile yang dibangun menggunakan Flutter. Aplikasi ini membantu pengguna untuk menghitung kebutuhan kalori harian minimum tubuh saat beristirahat, berdasarkan rumus medis **Mifflin-St Jeor**. Pengguna dapat memasukkan parameter jenis kelamin, tinggi badan, berat badan, dan usia untuk mendapatkan hasil yang akurat beserta rekomendasi kalori berdasarkan tingkat aktivitas fisik.

## ✨ Fitur Utama
* **UI/UX Modern & Responsif:** Menggunakan tema gelap (*Dark Theme*) yang elegan dan nyaman di mata.
* **Kustomisasi Input:** Menggunakan widget interaktif seperti *custom slider* untuk tinggi badan dan tombol khusus untuk mengatur berat badan serta usia.
* **Perhitungan Akurat:** Menggunakan formula Mifflin-St Jeor yang disesuaikan untuk pria dan wanita.
* **Interpretasi Hasil:** Menampilkan kategori metabolisme dan estimasi kebutuhan kalori harian untuk mempertahankan berat badan berdasarkan tingkat aktivitas (*Sedentary* vs *Active*).
